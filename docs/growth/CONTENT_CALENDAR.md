## What's deliberately not on this calendar

- Any paid promotion, influencer outreach, or sponsored post — not evaluated, not planned.
- Reposting the same launch announcement to the same community more than once — against the
  ground rules in `docs/growth/OUTREACH_TRACKER.md`.
- Any claim this calendar can't back up with something already true today (a testimonial, a user
  count, a "trusted by" logo) — none of those exist yet, so none appear here.
