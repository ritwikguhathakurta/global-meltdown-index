# Launch asset pack

This directory matches the master growth plan's Phase 8 file layout exactly. The same underlying
drafts also live in `docs/growth/LAUNCH_DRAFTS.md` in a more narrative form — this folder is the
structured, one-file-per-asset version the plan specifically asks for. **Nothing in either place
has been posted, published, or sent to anyone.**

| File | Purpose |
|---|---|
| `launch_positioning.md` | Condensed pitch for use across every channel |
| `launch_post_linkedin.md` | LinkedIn recap post |
| `launch_post_x.md` | X/Twitter thread |
| `launch_show_hn.md` | Hacker News Show HN submission |
| `launch_reddit.md` | r/SideProject and r/opensource drafts |
| `launch_indiehackers.md` | IndieHackers post (extra — not in the plan's original 11, kept since the draft already existed) |
| `launch_producthunt.md` | Product Hunt listing copy (extra, same reason) |
| `launch_email.md` | Generic outreach email template — **not pre-addressed to anyone real** |
| `technical_blog_outline.md` | Outlines for the three blog posts in the content calendar |
| `demo_video_script.md` | 60-90 second walkthrough script — not recorded |
| `faq.md` | Honest answers to the questions this launch will likely get |
| `outreach_tracker_template.csv` | Spreadsheet version of `docs/growth/OUTREACH_TRACKER.md` |
| `30_day_kpi_plan.md` | Weekly checkpoints tied to the content calendar; full mechanics live in `docs/growth/METRICS.md` |

Before using any of these: re-read `docs/growth/COMMUNITY_RESEARCH.md` for that specific channel's
current rules, and `docs/growth/DISTRIBUTION_PLAYBOOK.md` for the ground rules that apply to all of
them.
