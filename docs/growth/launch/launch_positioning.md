# Launch positioning (condensed)

Full version with evidence/validation: `docs/growth/POSITIONING.md`. This is the short form to
drop into any channel's "about" framing.

**One sentence:** An open-source systemic-risk terminal that turns free, official macro-financial
data into 24 independently-scored risk engines and one transparent composite score — every number
traceable to a named source, or honestly labeled `UNAVAILABLE`.

**Links to use everywhere:**
- Live site / public API: https://globalmeltdownindex.net
- Code (Apache-2.0): https://github.com/ritwikguhathakurta/global-meltdown-index
- No-signup proof: `curl https://globalmeltdownindex.net/api/gfmi`

**The one differentiator to lead with, if only one fits:** the project has turned down real,
technically-reachable data sources (CCIL, ACLED, OpenSanctions) because their own terms forbade the
automated use this needs — verifiable honesty, not a marketing claim.

**The one line that must appear anywhere this is described as a "risk score":** this is a current
risk signal, not a forecast — never imply a predicted crash, a date, or statistical certainty.
